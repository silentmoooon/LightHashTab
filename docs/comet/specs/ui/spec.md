# 用户界面显示优化规格 (UI Specification)

## 1. 主属性页 DPI 缩放与排版布局

- **DPI 动态缩放**:
  - 获取属性页窗口真实 DPI（通过 `GetDpiForWindow` 或系统备选 DPI 96）。
  - 所有间距（padding, gap）、控件高度（单行输入框、按钮）、图标尺寸（16x16 或 DPI 等比）均基于 DPI 缩放换算。
- **列表视图 (ListView)**:
  - 表头列 0：“算法”（Algorithm），宽度由原来的固定 85px 改为根据 DPI 缩放的基础宽度（如 105 DIP），确保“算法”以及“SHA-256”、“SHA-512”、“BLAKE3”等名称在高 DPI 下绝不截断。
  - 表头列 1：“哈希值”（Hash Value），宽度自适应视口宽度与实际哈希文本需求，允许横向滚动（启用水平滚动条），避免 SHA-512（128字符）被强制省略号截断。
  - 列表样式包含 `LVS_EX_FULLROWSELECT | LVS_EX_DOUBLEBUFFER | LVS_EX_INFOTIP | LVS_EX_LABELTIP`，并为列表项提供 Tooltip 提示，悬停展示完整算法哈希。
  - 字体：算法列使用系统界面字体，哈希值列使用 `Cascadia Mono` / `Consolas` 等宽字体，字体高度根据系统非客户区消息字号（`lfMessageFont`）及 DPI 精确换算，保证字形饱满且比例匀称。
- **比对与底部按钮区**:
  - 比对标签显示为“比对:”。
  - 比对输入框提供水印文字“在此粘贴哈希值以进行比对…”，右侧搭配自适应宽度的“粘贴”/“清除”按钮。
  - 状态标签位于左下方，支持状态文本展示（如“✔ 匹配成功: SHA-256”或“✖ 未匹配”）。
  - 右下操作按钮：“⚙ 设置”（宽度约 76 DIP）、“复制”（宽度约 56 DIP）、“复制全部”（宽度约 80 DIP），按 DPI 等比缩放，文字居中且留有舒适呼吸边距。

## 2. 算法设置模态对话框 (Algorithm Settings)

- **窗口样式与定位**:
  - 移除错误的 `DS_CONTROL` 标志，使用标准的模态对话框样式（`WS_POPUP | WS_CAPTION | WS_SYSMENU | DS_MODALFRAME | DS_CENTER`）。
  - 具有原生标题栏“算法设置”、系统边框与关闭按钮 [X]，支持 ESC 键或关闭按钮取消。
  - 弹出时在父属性页窗口正中央居中显示。
- **排版布局**:
  - 顶部标题提示：“选择要计算并显示的哈希算法:”。
  - 算法复选框采用双列规整排版（如左列：BLAKE3, SHA-256, SHA-512, SHA-384, SHA-1；右列：MD5, CRC32, XXH64, XXH128），间距与高度按 DPI 缩放。
  - 底部控制按钮分为两组：
    - 左侧配置辅助：[全选]、[默认]
    - 右侧确认取消：[确定]、[取消]
  - 窗口尺寸按 DPI 缩放计算，预留充足边距，杜绝任何“Select Al”或“Cance”此类因宽度不足导致的文本截断。

## 3. 哈希比对与匹配高亮

- 当比对框输入或粘贴哈希时：
  - 忽略大小写及可能的前缀（如 `0x`、引号）。
  - 匹配成功时：列表对应行整行以高亮色绘制（浅色模式下为柔和淡绿色背景与深绿文本，深色模式下为暗绿背景与亮绿文本）；状态栏输出“✔ 匹配成功: <算法名>”。
  - 无匹配时：若输入有效哈希字符达到 8 位以上，状态栏以红色输出“✖ 未匹配”。
  - 清空输入框时，清除高亮与状态提示。

## 4. 界面文案与提示中文化

- 属性页 Tab 标题：“文件哈希”
- 顶部文件信息：保留文件名、大小与耗时/吞吐量信息。
- 右键上下文菜单：
  - 复制哈希值
  - 复制算法与哈希
  - 复制全部哈希
  - 大写格式 (ABCDEF...)
  - 在 VirusTotal 上搜索
  - 在 Google 上搜索
  - ⚙ 算法设置...
- 复制成功反馈：“✓ 已复制 <算法名> 哈希值！” / “✓ 已复制全部哈希值！”
